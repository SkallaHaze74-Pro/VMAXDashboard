# VMAX Dashboard 6.0 Live AI Test

> Historischer Versionsstand. Die aktuelle App kann nach bewusster Einrichtung zu GitHub und externen KI-Providern übertragen; die damalige Aussage zum rein lokalen Betrieb ist kein aktueller Datenschutzvertrag.

Diese Testversion erweitert die Messfahrt-Aufnahme um:

- Live-Paketrate in Paketen pro Sekunde
- Live-Leistung und Maximalwerte, sobald Spannung/Strom dekodiert sind
- getrennte Datei `Live_Telemetrie.csv`
- lokales Lernprofil `Lernprofil.json`
- dauerhafte Zusammenführung von Kandidaten über mehrere Tests
- lokale Messfahrt-Historie im privaten App-Speicher
- Export unter `Downloads/VMAXDashboard/Messfahrt_Datum_Uhrzeit/`

## Datenschutz im damaligen Stand

In dieser Edition blieben Lern- und Verlaufsdaten lokal. Für den heutigen Stand gilt der aktuelle [Datenschutzentwurf](../privacy/DATENSCHUTZ_ENTWURF.md).

## Wichtig

Nur bestätigte Decoder werden als echte Messwerte dargestellt. Kandidaten aus dem Lernmodus sind Vermutungen mit technischer Bewertung.
